# SPEC Analysis Documentation

**Purpose**: Analysis documents for SPECs, including comprehensive analysis, cross-reference verification, and Taiga story creation reports.

## 📋 What Goes Here

### ✅ SPEC Analysis Documents
- Analysis summaries: `SPEC_{ID}_ANALYSIS_SUMMARY.md`
- Comprehensive analysis: `SPEC_{ID}_COMPREHENSIVE_ANALYSIS.md`
- Cross-reference verification: `SPEC_{ID}_CROSS_REFERENCE_VERIFICATION.md`
- Taiga stories: `SPEC_{ID}_TAIGA_STORIES_CREATED.md`

### ✅ SPEC-Related Reports
- Mismatch resolution: `SPEC_{ID}_MISMATCH_RESOLUTION.md`
- Resolution complete: `SPEC_{ID}_RESOLUTION_COMPLETE.md`

## 🚫 What Does NOT Go Here

- ❌ SPEC completion reports → `governance/reports/`
- ❌ SPEC implementation guides → `docs/guides/`
- ❌ SPEC README files → `specs/{ID}-spec-name/README.md`

## 📝 Naming Conventions

- Analysis: `SPEC_{ID}_ANALYSIS_SUMMARY.md`
- Comprehensive: `SPEC_{ID}_COMPREHENSIVE_ANALYSIS.md`
- Cross-reference: `SPEC_{ID}_CROSS_REFERENCE_VERIFICATION.md`
- Taiga stories: `SPEC_{ID}_TAIGA_STORIES_CREATED.md`

See [docs/DOCUMENT_ORGANIZATION.md](../DOCUMENT_ORGANIZATION.md) for full rules.
