# Security Documentation

**Purpose**: Security-related documentation, guides, and policies.

## 📋 What Goes Here

### ✅ Security Documents
- Security guides: `TENANCY_GUARD_USAGE.md`
- Security policies: `SECURITY_BANDIT_POLICY.md`
- Security monitoring: `MULTIPART_SECURITY_MONITORING.md`
- Security middleware: `SECURITY_MIDDLEWARE_SUMMARY.md`

## 🚫 What Does NOT Go Here

- ❌ Completion reports → `governance/reports/`
- ❌ Security analysis → `docs/spec-analysis/` (if SPEC-related)

## 📝 Naming Conventions

- Security docs: `{TOPIC}_SECURITY.md` or `SECURITY_{TOPIC}.md`
- Usage guides: `{TOOL}_USAGE.md`

See [docs/DOCUMENT_ORGANIZATION.md](../DOCUMENT_ORGANIZATION.md) for full rules.
