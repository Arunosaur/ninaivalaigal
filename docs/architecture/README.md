# Architecture Documentation

**Purpose**: System architecture, design decisions, and architectural documentation.

## 📋 What Goes Here

### ✅ Architecture Documents
- Architecture diagrams: `ARCHITECTURE_DIAGRAM.md`
- Architecture decisions: `FRONTEND_ARCHITECTURE_DECISION.md`
- Design documents: `UNIFORM_ARCHITECTURE_DESIGN.md`
- Shared data architecture: `SHARED_DATA_ARCHITECTURE.md`

## 🚫 What Does NOT Go Here

- ❌ Completion reports → `governance/reports/`
- ❌ SPEC analysis → `docs/spec-analysis/`
- ❌ Implementation guides → `docs/guides/`

## 📝 Naming Conventions

- Architecture docs: `{TOPIC}_ARCHITECTURE.md` or `ARCHITECTURE_{TOPIC}.md`
- Design decisions: `{TOPIC}_ARCHITECTURE_DECISION.md`

See [docs/DOCUMENT_ORGANIZATION.md](../DOCUMENT_ORGANIZATION.md) for full rules.
