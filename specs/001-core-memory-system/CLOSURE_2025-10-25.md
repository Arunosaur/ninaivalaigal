## Live Verification Workflow (Copy-Paste Ready)

### Step 1: Health Check
```bash
# Verify all services healthy
curl http://localhost:13390/health  # Core API
curl http://localhost:13393/health  # Memory Service
```

### Step 2: Authenticate
```bash
# Obtain JWT token
export TEST_AUTH_TOKEN=$(curl -s -X POST http://localhost:13390/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"test@example.com","password":"testpass123"}' `# pragma: allowlist secret` \
  | jq -r '.access_token')

echo "✅ Token obtained: ${TEST_AUTH_TOKEN:0:20}..."
```

### Step 3: Store Memory
```bash
# Store a verification memory
curl -X POST http://localhost:13393/memory \
  -H "Authorization: Bearer $TEST_AUTH_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "note",
    "source": "verification",
    "data": {
      "context": "test-context",
      "content": "SPEC-001 validated memory",
      "timestamp": "'$(date -u +"%Y-%m-%dT%H:%M:%SZ")'"
    }
  }'

echo "✅ Memory stored successfully"
```

### Step 4: Recall Memory
```bash
# Recall memories by context
curl -X GET "http://localhost:13393/memory?context=test-context" \
  -H "Authorization: Bearer $TEST_AUTH_TOKEN" | jq

echo "✅ Memory recalled successfully"
```

### Step 5: Test Shell Hook
```bash
# Configure shell hook
source adapters/shell_hooks/store_memory.sh
export NINA_AUTH_TOKEN="$TEST_AUTH_TOKEN"
export NINA_CONTEXT="test-context"
export NINA_MEMORY_SERVICE_URL="http://localhost:13393"

# Verify status
nina_status

# Execute test command (auto-captured)
echo "SPEC-001 shell hook verification"

# Verify auto-capture
sleep 2
curl -X GET "http://localhost:13393/memory?context=test-context" \
  -H "Authorization: Bearer $TEST_AUTH_TOKEN" \
  | jq '.[] | select(.type == "terminal_command")'

echo "✅ Shell hook verified successfully"
```
