## Organization Principle

**Phase summaries live here**, **individual SPECs live in numbered directories** (`../121-frontend-shared-library/`, etc.), and **SPEC_INDEX.md** remains in the root `specs/` directory as the central navigation hub.

This structure:
- ✅ Keeps root specs/ directory clean and navigable
- ✅ Groups related phase documentation together
- ✅ Provides historical context for implementation phases
- ✅ Makes it easy for new contributors to understand project evolution
