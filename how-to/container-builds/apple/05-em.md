# Enhanced Memory (EM) Container - Apple Container CLI
**Mem0ai-powered sidecar service for memory management**

---

## Container Information

- **Name**: `ninaivalaigal-dev-em`
- **Image**: `nina-em:arm64`
- **Base**: `python:3.11-slim`
- **Architecture**: ARM64
- **Port Mapping**: `7070:7070` (dev)
- **Purpose**: Memory management, context tracking, intelligent retrieval

## What's Inside

### Application
- **FastAPI sidecar** - Lightweight memory service
- **Mem0ai** - Enhanced memory engine
- **Database**: Connects to main PostgreSQL
- **Purpose**: Memory CRUD, context management, retrieval


## Dockerfile

**Location**: `/Users/swami/WorkSpace/ninaivalaigal/Dockerfile.em`

```dockerfile
FROM python:3.11-slim

WORKDIR /app

# Install system dependencies
RUN apt-get update && apt-get install -y \
    gcc \
    libpq-dev \
    && rm -rf /var/lib/apt/lists/*

# Install Python dependencies
RUN pip install --no-cache-dir "mem0ai" fastapi uvicorn[standard] pydantic

# Copy sidecar app
COPY sidecar/ ./sidecar/

EXPOSE 7070

CMD ["uvicorn", "sidecar.main:app", "--host", "0.0.0.0", "--port", "7070"]
```

## Runtime Configuration

### Start Container

```bash
# Get database IP
DB_IP=$(container inspect ninaivalaigal-dev-db | jq -r '.[0].networks[0].address' | cut -d'/' -f1)

# Start EM
container run -d --name ninaivalaigal-dev-em \
  -p 7070:7070 \
  -e DATABASE_URL="postgresql://nina:change_me_securely@${DB_IP}:5432/nina" \  # pragma: allowlist secret
  nina-em:arm64

# Wait for startup
sleep 5
```

### Environment Variables

| Variable | Required | Default | Description |
|----------|----------|---------|-------------|
| `DATABASE_URL` | No | - | PostgreSQL connection (optional) |
| `MEM0_CONFIG` | No | - | Mem0ai configuration JSON |

## Troubleshooting

### Container Won't Start

```bash
# Check logs
container logs ninaivalaigal-dev-em

# Common issues:
# 1. Port conflict
lsof -i :7070

# 2. Missing dependencies
container run --rm nina-em:arm64 pip list | grep mem0ai
```

### Cannot Connect to Database

```bash
# Check database is running
container list | grep ninaivalaigal-dev-db

# Test connection
DB_IP=$(container inspect ninaivalaigal-dev-db | jq -r '.[0].networks[0].address' | cut -d'/' -f1)
psql "postgresql://nina:change_me_securely@${DB_IP}:5432/nina" -c "SELECT 1;"  # pragma: allowlist secret

# Restart EM with correct DB_IP
container stop ninaivalaigal-dev-em
container delete ninaivalaigal-dev-em

container run -d --name ninaivalaigal-dev-em \
  -p 7070:7070 \
  -e DATABASE_URL="postgresql://nina:change_me_securely@${DB_IP}:5432/nina" \  # pragma: allowlist secret
  nina-em:arm64
```

### API Cannot Reach EM

```bash
# Check EM is running
container list | grep ninaivalaigal-dev-em

# Get EM IP
EM_IP=$(container inspect ninaivalaigal-dev-em | jq -r '.[0].networks[0].address' | cut -d'/' -f1)

# Test from API container
API_IP=$(container inspect ninaivalaigal-dev-api | jq -r '.[0].networks[0].address' | cut -d'/' -f1)
container exec ninaivalaigal-dev-api curl http://${EM_IP}:7070/health
```
